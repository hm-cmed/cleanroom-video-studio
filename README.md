# クリーンルーム動画スタジオ

医療者教育・医療広報のショート動画シリーズを、**クリーンルーム方式**で作るためのブラウザ用ツールです。

論文やガイドラインの文章をそのまま使わず、事実と数値だけを「事実カード」に書き出し、そのカードだけを根拠に台本を作ります。台本の各場面がどのカードにもとづくかが残るため、監修と訂正がしやすく、著作権の問題も避けられます。

**使ってみる**：https://hm-cmed.github.io/cleanroom-video-studio/

インストールは要りません。Chrome か Edge の最新版で開いてください。作業の内容は、使っているブラウザの中だけに保存されます。

## 作業の流れ

| 工程 | すること | 主に担う人・道具 |
|---|---|---|
| 1 企画 | 責任者・公開範囲・高リスク素材（段階0）と、学習目標（段階1）を決める。リスク区分（低・中・高・停止）を自動で表示 | あなた |
| 2 事実カード | チャットAIへの調査依頼文を作る → 答えを貼る → 形式を自動点検 → 人が一次資料で確かめて確認者・確認日を記入（段階2〜5） | チャットAI＋あなた |
| 3 シリーズ構成 | 回ごとにカードを2〜3枚割り当て、回の学習目標と自分で決めた構成を書く | 自動＋あなた |
| 4 台本 | 事実カードと学習目標だけを材料に、依頼文 → 貼り付け → 根拠カード・数字・禁止表現・字幕の速さを自動照合。AI の利用と人が直した場面を記録（段階6） | チャットAI＋自動 |
| 5 監修・監査 | 監修者が字幕と根拠カードを見比べ、監査担当が類似性と権利を確認（段階8・様式4）。両方そろうと承認。承認後に台本を変えると承認は外れる | 監修者・監査担当 |
| 6 動画 | 音声を先に用意し、その長さに合わせて場面を切り替えて書き出す | 自動 |
| 7 公開 | 最終チェックリスト、権利表示（CC BY など）、出典・監修者・版・AI作成の表示を入れた説明文、記録様式を含むシリーズ一式（ZIP）（段階9） | 責任者 |
| AIに頼む | ブラウザだけではできない作業の依頼文を、Claude Code・Codex・その他向けに出す | コード生成AI |

### 「AIに頼む」で案内する作業

- 高音質のナレーションで動画を一括作成する（自分のパソコンで。`local/` を使う）
- WebM の動画を MP4 に変換する
- 事実カードの文献番号（DOI・PMID）とライセンスを API で照合する → 結果をブラウザに貼り戻す
- 新しい挿絵（SVG）を作る → ブラウザに貼り戻す
- 自分の団体のサイトとして公開する（GitHub Pages）
- 定期的な自動作成の仕組みを作る（上級）

## フォルダ

| 場所 | 中身 |
|---|---|
| `index.html` `app.js` `render.js` `prompts.js` | ブラウザで動くスタジオ本体（ビルド不要） |
| `config.js` | 表示の設定（アプリ名、開発者、助成の表記、ライセンス）。団体で使うときはここを書き換える |
| `sample.js` | 見本の事実カード6件と台本1本（架空の団体「サンプル消化器ケア協会」の広報用という想定。内容は Rome V にもとづく） |
| `local/` | 自分のパソコンで動画を一括作成するプログラム（Python・ffmpeg） |
| `CLAUDE.md` `AGENTS.md` | このレポジトリでコード生成AI に作業させるときのルール |

## 自分の団体で使う

1. このレポジトリをフォークし、Settings → Pages で `main` ブランチのルートを公開します。
2. `config.js` の `appName` や `developer` を書き換えます。助成の表記（`grants`）は、元の開発の記録として残してください。
3. 手順が分からないときは、スタジオの「AIに頼む」→「自分の団体のサイトとして公開する」を開くと、使う AI に合わせた依頼文が出ます。

## 準拠するマニュアル

制作の手順は、『著作権等に配慮した教育コンテンツ作成マニュアル』Version 1.2（公開版、札幌医科大学 医療人育成センター 教育開発研究部門、制定 2026年7月16日・改訂 2026年10月20日）の標準作業手順（段階0〜9）に沿っています。このツールは、複数の資料から事実を取り出して新しく作る「独立創作型」を支援します。既存の出版物を許諾を得て動画化する「許諾型」は対象外です。

書き出す ZIP の `records/` には、マニュアルの記録様式に対応するファイルが入ります。

| ファイル | 様式 |
|---|---|
| `form1_fact_verification.csv` | 様式1 事実抽出・検証票 |
| `form2_rights_ledger.csv` | 様式2 素材・権利台帳 |
| `form3_independent_creation.md`、`ai_log.csv` | 様式3 独立創作記録と生成AIの利用記録 |
| `form4_audit_<回>.md` | 様式4 類似性・公開前監査票（監修の記録を含む） |
| `final_approval.md` | 10．最終チェックリストと最終承認 |

## 守るルール（クリーンルーム方式）

1. 論文やガイドラインの文章・表・図を写さない。事実と数値だけを自分の言葉で書く。
2. 数値は一次資料で確かめたものだけ。二次資料から取ったものはそう書いておく。
3. 文献番号（DOI・PMID）やライセンスは、確かめられたものだけを書く。
4. 有料の論文・書籍・出版社の PDF の全文を、許諾なく AI に読み込ませない。患者情報・個人情報・試験問題を AI に入力しない。
5. 台本の各場面には根拠のカードIDを付ける。カードにない数字は足さない。AI を使った記録を残す。
6. 公開は、監修と類似性の監査を経て承認された動画だけ。AIで作ったこと、出典、版を示す。
7. 一般向けでは薬の名前を出さず、実在の人物の映像や声、ロゴを使わない。

本ツールは制作の手順を支援するもので、医学的内容の正確さや、権利侵害がないことを保証するものではなく、法律上の助言でもありません。公開する内容の最終判断は各団体の責任者・監修者が行い、高額・商用・大規模公開・権利関係が不明な案件・国外公開は、所属機関の法務・知財担当または弁護士に確認してください。
