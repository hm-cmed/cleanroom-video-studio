# コード生成AI向けの作業ルール

この `agent-kit/` フォルダは、コード生成AI（Claude Code、Codex、Cursor 等）に縦型ショート動画の制作パイプラインを実装させるためのキットです（クリーンルーム動画スタジオの一部）。作業はこのフォルダの中で行い、フォルダの外（ブラウザ版のスタジオ）は変更しないでください。作業の前に、次の順で読んでください。

1. [docs/SPEC.md](docs/SPEC.md) — 実装仕様（何を作るか、受け入れ基準）
2. [docs/FACT_CARDS.md](docs/FACT_CARDS.md) — 医学の事実票の参照方法
3. [../DISCLAIMER.md](../DISCLAIMER.md) — 免責事項と配信前の監修義務
4. [THIRD_PARTY.md](THIRD_PARTY.md) — 第三者のソフトウェア・素材の扱い

## 必ず守ること

### 進め方
- 実装前に、仕様の不明点・矛盾を箇条書きで利用者に質問する。
- `docs/SPEC.md` 第9章のフェーズ順に実装し、各フェーズの受け入れ基準を自分で実行して結果を報告してから次へ進む。
- ソフトウェアのインストール、PATH・システム設定の変更は、実行前に必ず利用者の承認を得る。
- 利用者の OS を確認し、Windows なら PowerShell のコマンドで案内する（`brew` や bash 専用の書き方を使わない）。

### 権利
- 第三者のコード・フォント・音源・画像・動画をリポジトリに追加しない。必要な場合は `THIRD_PARTY.md` にリンクと入手方法を書き、利用者が各自で入手する形にする。
- 他のリポジトリのコードを複製しない。参考にした場合は `THIRD_PARTY.md` にリンクを書く。
- 既存のロゴ・キャラクター・実在人物の顔・他人の作品に似せた図を描かない。図や絵は SVG・CSS で独自に描く。
- 新しく書くコードは MIT License（レポジトリ直下の `LICENSE`）で公開されることを前提にする。

### 医学的内容
- 医学的な主張は、[hm-cmed/cleanroom-facts](https://github.com/hm-cmed/cleanroom-facts) の事実票を根拠にし、台本に根拠カードIDを残す。記憶や推測で医学的事実を書き足さない。
- 事実票の多くは専門家の監修前である。`verified_expert` 以外のカードを使った台本・動画は「監修前・配信不可」として扱い、利用者にその旨を毎回明示する。
- 動画を書き出したら、`templates/medical-review-checklist.md` から `out/<slug>/medical_review.md` を作り、「専門家の監修が完了するまで配信しないでください」と利用者に伝える。
- SNS への自動投稿機能は作らない。

### 品質
- レンダリングは決定論的にする（`seek(t)` で描画、実時間に依存しない）。
- 生成物（`out/`、音声、動画）と素材（`assets/` 配下）はコミットしない。
